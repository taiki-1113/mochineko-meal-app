# もちねこ食事アプリ

iPhone Safari向け、GitHub Pagesで配信できる静的PWA。ビルド・APIキー・アカウントは不要です。

## 実装した内容

- 参考デザインを基にした暖かい室内背景、丸いホームのもちねこ、子ども選択、食事区分、黄色の開始ボタン、珊瑚色の終了ボタン。
- ひらがなの名前を最大3人登録・編集・削除。選択名を通常メッセージ4回に1回差し込み。
- 成長01〜09＋体型10の睡眠。食べる15秒・休む8秒、25%ごとの小さな弾み。
- 食事中は向かいの食卓に座り、専用9体型×3ポーズで「ひとくち→もぐもぐ→飲み込む」。お皿の食べ物も減り、時間とともにおなかが丸くなります。目安時間後は満足して休憩。胸元の疑似的な手の重ね描きは廃止しました。
- 通常文27＋名前入り9＋タップ3。通常60〜120秒間隔、吹き出し8秒、消えてから3秒のタップ制限。
- 鳴き声4系統×3種類＋寝息。同梱WAVをWeb Audioで再生。読み上げ・外部API・BGMは使いません。
- 音ON/OFFを端末に保存。OFFでも吹き出しと動きは継続。
- 開始時に計測し、8秒の開始演出。終了確認後、8秒と音の終了を待ってホームへ戻る。
- 設定・進行のローカル保存、再読み込み復帰、Wake Lock、必須資産のオフラインキャッシュ。

## ローカル起動

このフォルダーで `python -m http.server 4173 --bind 127.0.0.1` を実行し、`http://127.0.0.1:4173/` を開きます。HTTPSまたはlocalhostでサービスワーカーが動作します。ファイル直接起動は対象外です。

## ファイル

- `index.html` / `styles.css`：画面・レスポンシブ表示。
- `app.js`：状態、登録設定、吹き出し、成長、睡眠、復帰。
- `messages.js`：確定文案36種類＋タップ3種類と抽選。
- `audio.js`：単一音源、音ON/OFF、寝息。
- `assets/character/`：体型PNGと表示範囲メタデータ。
- `assets/background/room.png`：食事画面の背景。`home-sky.png`：窓から青空が見えるホーム専用背景。
- `assets/audio/`：合成鳴き声12種類＋寝息WAV。
- `assets/MEDIA.md`：素材の出自と画像生成プロンプト。
- `要件.md` / `design-requirements.md`：2026-10-27の合意済み仕様。

## 音と画像の品質

鳴き声はオリジナル波形合成による猫風音です。実猫の録音ではありません。設定内「なきごえを ためす」で試聴できます。自然さ・聞き心地の最終確認は利用者による試聴が必要です。

体型05は市松背景を真の透過へ修正した派生素材を使います。支給素材の縁や角度の差は一部残ります。手を合わせる演出は既存画像に重ねる簡易的な前足アニメーションで、専用のポーズ・口形差分はありません。

## GitHub Pages

`.github/workflows/pages.yml` はmainへのpushまたは手動起動で、必要なアプリファイルとPNG・WAVのみを `_site` にまとめて公開します。GitHubのPagesのSourceはGitHub Actionsを選択します。仕様書・参考デザイン・生成ツールは配信しません。

公開URL： https://taiki-1113.github.io/mochineko-meal-app/

公開リポジトリの main ブランチを更新すると、GitHub Actionsが最新版を配信します。ローカルの公開作業用コピーは `.github-publish/` に分離します。

## オフライン・保存

オンラインで初回表示後「オフラインの じゅんびが できたよ」が表示されたら利用可能です。新バージョンの必須資産をまとめてキャッシュし、切り替え時は進行情報から復帰します。保存はlocalStorageのみで、食事履歴・解析・外部送信はありません。iOS Safari/PWAの消灯、復帰後の音再開、電話・通知の割り込み、文字拡大は実機で最終確認してください。

## プレイ画面のフォント

吹き出し・終了ボタンなどに `assets/fonts/ZenMaruGothic-Bold.ttf` を同梱して使います。Google Fontsの公式配布から取得し、SIL Open Font Licenseを `assets/fonts/OFL-ZenMaruGothic.txt` に同梱しています。実行時に外部フォントサービスへ通信しません。
