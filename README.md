# もちねこ食事アプリ

GitHub Pagesで公開するiPhone向けPWAです。採用デザインは `デザイン/もちねこ キャラクターデザインシート_3D.png`。食事前・食事中・食後・睡眠の4つの姿に、3Dシートから切り出したキャラクター画像を使用しています。公開用画像は `assets/character/` に含まれます。

## 含まれる機能

- 子どものニックネームを最大3人まで端末内に保存
- 朝・昼・夜ごとの食事時間設定（10〜60分、5分刻み）
- いただきます、食事中のタップ反応、ごちそうさま確認
- 経過時間に応じた体型変化と睡眠状態
- 再読み込み後の進行中セッション復元
- Web App Manifest、サービスワーカーによるオフラインキャッシュ
- GitHub ActionsによるGitHub Pagesデプロイ

音声はiPhoneの日本語音声合成を利用します。利用可能な声や再生可否は端末・OS・ユーザー操作に依存します。要件にある事前生成音声ファイルはまだ含めていません。

## GitHub Pages公開

1. このフォルダの内容をGitHubリポジトリの `main` ブランチに配置します。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` にpushするか、Actions画面から **Deploy to GitHub Pages** を手動実行します。
4. Actionsのデプロイ結果に表示されたHTTPS URLをiPhoneのSafariで開きます。
5. 初回表示後にホーム画面へ追加し、オンラインで一度読み込みが完了してからオフライン動作を確認します。

ワークフローは公開用の `_site` を作り、アプリの実行に必要なファイルだけを公開します。要件書とデザイン資料は公開物に含めません。

## ローカル確認

サービスワーカーはHTTPSまたはlocalhostでのみ動作します。ファイルを直接開くのではなく、ローカルHTTPサーバーでこのフォルダを配信して確認してください。

## 保存と通信

子どもの登録、食事時間、進行中セッションはブラウザーの `localStorage` に保存します。アカウント、解析サービス、アプリ独自のサーバー送信はありません。初回および更新時にはGitHub Pagesからアプリ資産を取得します。
